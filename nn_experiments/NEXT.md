## 이번에 통한 것 — 시즌 가중치 (+22 판별력)

```python
sample_weight = 2.0 ** (season - 2019)     # 2024 가 2019 의 32배
# 유효표본 720,829행 (49%). 버려지는 행은 하나도 없다
```

리그 성공률이 2019 54.95% -> 2024 48.97% 로 계속 밀리는데 옛 시즌을 같은 무게로
보고 있었다. 관문 판별력 886.9 -> 908.9.

**결정적으로, 예측 평균이 0.4994 -> 0.5000 으로 오히려 올라가면서 점수가 올랐다.**
수준 보정이 아니라 순수 판별력 향상이다.

decay 스윕 (관문, 판별력 기준):
```
decay    1.0    1.6    2.0    2.5    3.2    4.5    6.5
판별력  886.9      -  908.9  900.5  905.1  903.3  893.2
```
2.0~4.5 가 고원, 6.5 부터 하락. 고원의 왼쪽 끝인 2.0 채택.

### 왜 이걸 놓쳤었나 — 되풀이하지 말 것

'최근 시즌만 쓰기' 는 이미 재봤고 **-27 이라 기각했었다**(849.0 -> 823.3).
극단이 나쁘다고 방향까지 기각한 것이 실수였다. 표본을 잘라내면 '안 변하는 신호
(투수 실력, 볼카운트 효과)' 까지 굶는다. 가중치는 표본을 안 버리고 드리프트만 줄인다.

시즌가중 도입 후 다시 잰 값들. 전부 현행이 최적이다.

```
시즌가중 decay     2.0        고원 2.0~4.5
월 단위 가중치      기각        판별력 -1.7. 시즌 내 기울기 부호가 매년 뒤집힌다
                              (2021 -0.479 / 2023 +0.314 %p/월)
라우팅 비율        0.6        0.4~0.6 이 907.2/907.1/906.7 로 평평
MLP 비중          0.20       0.15~0.25 가 912.6/912.6/911.6 로 평평
shift            -0.0145    1021 로 역산하면 최적 -0.018, 차이 +0.3
```

시즌가중 후 **전체단독 862.2 / R단독 862.0 으로 같아졌다.** 균등가중 시절 전체모델의
퓨처스 편향을 R단독 라우팅이 잡아주던 역할을 시즌가중이 흡수했다. 그래서 라우팅
곡선이 평평하다. 라우팅을 빼도 되지만 점수가 오르진 않는다.
