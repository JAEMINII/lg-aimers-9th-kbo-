## 최종 구조 (submit_89)

4계열 앙상블 위에 로짓 공간 보정 사슬을 얹은 형태. 추론은 순수 numpy 로만 돌아간다
(torch·sklearn·catboost 불필요 — 학습된 트리와 신경망 가중치를 npz 배열로 내보냈다).

```
테스트 행 1개
   ├─ CatBoost   58피처 · 시드3 × 브랜치3 · depth4/400트리 · 시즌가중 2.0^(y−2019)   w 0.393
   ├─ TabM       BatchEnsemble k=32 · Stage1 2ep + Stage2 · 퓨처스 브랜치는 2023+     w 0.060
   ├─ DIN        시퀀스 attention (투수 직전 16구 × 현재 상황 질의)                    w 0.167
   └─ MultiState 보조 5범주 softmax → P(성공) · 1군 state6 / 퓨처스 ms_s2             w 0.381
                                    ↓  (cold 투수 행은 별도 가중 0.45/0.10/0.25/0.20)
   로짓 변환 후 가산 — 전부 학습 시점에 얼린 lookup·상수, 행 단위 조회
      pcnt +0.12   투수 × 볼카운트, 자기 평균 대비 편차 (계층수축 κ=300)
      pout −0.10   투수 × 아웃카운트 역보정
      bcnt +0.05   타자 × 볼카운트
      csf  +0.10   퓨처스 행 현시즌 편차
      rev  −0.45   복원 reverse 성분 (투수 × 타자손 × 볼카운트)
      t13          13팀 R행 상수 — 투수측 월별 +0.105/+0.08/+0.055, 타자측 +0.06
                                    ↓
   합의-샤픈  4계열 로짓이 행내 중앙값에서 0.08 이내인 행만 z₀ + 1.05·(z − z₀)
                                    ↓
   온도·시프트  p = σ(1.04·z − 0.007)
```

서버 추론 4.2분(상한 8분), 행 독립성 실측 0.00e+00.

## 이 대회에서 통한 것

1. **결함 수정** — 코사인 스케줄러 주기 오류(LB +21.6), `plat_dev` 누출(+11)
2. **학습 분포 조정** — 시즌가중, 퓨처스 브랜치를 체제 전환 이후로만 학습
3. **표적 세분화** — 표적이 "스트라이크"가 아니라 "의도대로 갔나"임을 밝히고,
   as-of 차분으로 숨은 판정을 복원해 실패를 세 갈래로 나눠 학습 (+19)
4. **다양성** — 상관 0.94 이하 구성원 한 자리를 채운 DIN (+6)
5. **전행 상수·lookup 보정** — 관문 → LB 전이율 0.77~0.9 로 유일하게 안정적이던 클래스
6. **실패 제출의 역산** — 빗나간 강베팅의 낙폭에서 잔차 크기·부호를 계측해 다음 장에 반영 (+19)

새 모델 계열 추가, 용량 증대, 조각 라우팅은 예외 없이 실패했다. 라벨 분산의 0.93%만
학습 가능한 신호였기 때문이다 — 표현력이 아니라 규제·보정·다양성의 문제였다.
