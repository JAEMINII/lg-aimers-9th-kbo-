# Trackman / LUPI 규칙 확인 — 2026-08-30

공식 FAQ 원문: <https://dacon.io/competitions/official/236743/talkboard/417082>

| 사용 경로 | 판단 | 운영상 제약 |
|---|---|---|
| `train.csv`와 `trackman_history.csv`로 투수·타자 익명 ID 대응을 복원 | 가능 | 공식 답변이 ID 대응 추정과 이전 시즌 Trackman 요약 피처를 모두 허용했다. |
| Trackman 과거 기록으로 만든 선수 단위 요약을 한 평가 행에 결합 | 가능 | 평가 행 하나와 학습 데이터에서 고정한 표만 사용해야 한다. 평가 데이터의 다른 행·전체 분포를 참조하면 안 된다. |
| 학습 행의 **현재 투구** Trackman을 교사 입력 또는 보조 표적으로 사용하고, 학생은 허용 피처만 입력으로 사용 | 가능 | FAQ는 제공된 Trackman이 학습 데이터 기간만 포함하므로 학습 데이터 범위의 활용에 별도 제약이 없다고 답했다. 최종 `script.py`에는 현재 투구 Trackman을 읽거나 필요로 하는 경로를 넣지 않는다. |
| `train.csv`의 다음 행에서 복원한 reverse/middle 상태를 보조 표적으로 사용 | 가능 | FAQ는 학습 데이터 내부에는 제약이 없다고 답했다. 추론에서는 해당 라벨 또는 평가 데이터의 다른 행을 읽지 않는다. |
| 제출 점수로 모델·상수·앙상블 가중치를 선택 | 가능 | FAQ가 명시적으로 허용했다. 다만 개별 평가 행 예측을 평가 데이터 분포/다른 행으로 보정하는 것은 금지다. |

제출 전 필수 감사:

1. `script.py`가 `test.csv`와 고정 모델/학습 산출물만 읽는지 확인한다.
2. Trackman 원본, 학습용 soft label, 학습 행별 보조 라벨은 배포 파일에 넣지 않는다.
3. 행 순서 섞기 및 부분집합 실행에서 동일한 행 예측이 정확히 같은지 확인한다.
4. 모든 제출물이 규칙 검토 대상이므로, 검증 중인 미완성/규칙 불명확 모델은 제출하지 않는다.
